Configurazione richiesta

Per collegare la dashboard al database condiviso, apri questo file con un editor di testo e incolla il Project URL e la chiave anon public del tuo progetto Supabase nella sezione CONFIG SUPABASE in cima allo script. Salva e ricarica la pagina.

I due valori sono in Supabase → Project Settings → API. La guida di attivazione allegata spiega ogni passaggio.
